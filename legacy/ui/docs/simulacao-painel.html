O Painel com a proposta de tokens

À esquerda, o mockup original (Countify/docs/design/mockup). À direita, o mesmo Painel com toda cor trocada pelo token da proposta (var(--t-accent), var(--t-text2)…; os papéis apontam para os degraus das escalas de 10 tons).

Resultado: 0 pixel diferente nas quatro telas (celular e computador, claro e escuro). A proposta não muda nada do que o mockup já define: ela só acrescenta o que falta (escalas, aviso, tamanhos xs–xl, camadas, durações, letra de largura fixa).
