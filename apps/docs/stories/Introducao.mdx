# Countify Design System

Os componentes, os tokens e as regras de interface da Countify, para **React na web**, **Electron** e **React Native**,
com a mesma API nos três. Tudo segue a identidade visual da Countify: cores, letra, espaços, cantos e os modos claro e
escuro.

## Instalação

Os pacotes ficam no GitHub Packages da organização `countify-oficial`. O GitHub pede um token para instalar, mesmo nos
pacotes públicos: crie um token clássico em **GitHub → Settings → Developer settings → Personal access tokens** com o
escopo `read:packages` e grave no `~/.npmrc` da sua máquina (nunca no repositório):

```ini
//npm.pkg.github.com/:_authToken=SEU_TOKEN
```

No projeto, aponte o escopo para o GitHub, num `.npmrc` na raiz:

```ini
@countify-oficial:registry=https://npm.pkg.github.com
```

E instale com o gerenciador que o projeto usa:

```bash
# pnpm
pnpm add @countify-oficial/core @countify-oficial/provider @countify-oficial/tokens

# npm
npm install @countify-oficial/core @countify-oficial/provider @countify-oficial/tokens

# yarn
yarn add @countify-oficial/core @countify-oficial/provider @countify-oficial/tokens
```

O React 19 é dependência par: o projeto precisa ter o `react` e o `react-dom`.

## Configuração

Carregue os estilos uma vez, na entrada do app, e envolva o app no `CountifyProvider`:

```tsx
import "@countify-oficial/tokens/fonts.css";
import "@countify-oficial/tokens/tokens.css";
import "@countify-oficial/core/styles.css";
import { CountifyProvider } from "@countify-oficial/provider";
import { createRoot } from "react-dom/client";

createRoot(document.getElementById("root")!).render(
  <CountifyProvider defaultColorScheme="auto">
    <App />
  </CountifyProvider>,
);
```

Cada extensão tem o próprio CSS: ao instalar `@countify-oficial/dates`, por exemplo, importe também
`@countify-oficial/dates/styles.css`.

## Primeiro componente

```tsx
import { Button, Group, TextInput } from "@countify-oficial/core";

export function NovaLoja() {
  return (
    <form>
      <TextInput label="Nome da loja" placeholder="Lume Jardins" />
      <Group justify="flex-end" gap="sm">
        <Button variant="outline">Cancelar</Button>
        <Button type="submit">Salvar</Button>
      </Group>
    </form>
  );
}
```

## Modo claro e escuro

O `CountifyProvider` segue o sistema (`"auto"`) ou fixa um modo (`"light"`, `"dark"`). Os componentes trocam de cor
sozinhos, pelos tokens. Para mudar o modo em tempo de execução:

```tsx
import { useCountifyTheme } from "@countify-oficial/provider";

const { colorScheme, setColorScheme } = useCountifyTheme();
setColorScheme(colorScheme === "dark" ? "light" : "dark");
```

Nesta documentação, o botão **Modo**, na barra de cima de cada exemplo, faz a mesma coisa.

## React Native

Mesmos nomes e mesmas props, importados de `@countify-oficial/native`. O provider e os tokens são os mesmos pacotes:
o Metro escolhe a versão nativa sozinho.

```tsx
import { Button } from "@countify-oficial/native";
```

## Personalizar

Padrões por componente, para o app inteiro, pelo tema do provider:

```tsx
import { createTheme } from "@countify-oficial/provider";

const theme = createTheme({
  components: {
    Button: { defaultProps: { size: "sm" } },
  },
});

<CountifyProvider theme={theme}>…</CountifyProvider>;
```

Cada componente também aceita `classNames` e `styles` em cada parte interna. Veja a seção **Anatomia** no
[Guia de botões](?path=/docs/botões-guia-de-uso--docs).
